## Notes
- Read_from_Head On replayed old log files once. Loki rejected lines more than 1h older than
  the newest line of the same stream (HTTP 400 'entry too far behind'), and Fluent Bit's health
  check reported unhealthy for about a minute, then recovered by itself. No errors since.
- Revision 1 counted web's Instana agent-lookup lines ('[lis] Error: lookup requests for all
  agent host candidates failed') as real errors and dispatch's 'Error Percent is 0' as an error.
  Revision 2 marks the first as instana_noise and only counts UPPER-CASE or [bracketed] level
  words. Lines already stored keep their old labels, so 1h windows still include them.
- level=unknown: lines that carry no level, mostly dispatch (Go's standard log package has no
  levels), load-gen output and blank lines.
